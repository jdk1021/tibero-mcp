Let AI agents read your Tibero schema. Nothing gets written unless you say so. AI 에이전트가 Tibero 스키마를 읽습니다. 허락하기 전에는 아무것도 쓰지 않습니다.

An MCP server for Claude Code, Codex and Cursor that finds tables by their Korean comments, explains keys and plans, and runs only the queries you would let a new colleague run. Claude Code, Codex, Cursor에서 쓰는 MCP 서버입니다. 한글 주석으로 테이블을 찾고, 키와 실행 계획을 설명하며, 새로 온 동료에게 허락할 만한 쿼리만 실행합니다.

claude mcp add -s user tibero -- uv --directory ./tibero-mcp run tibero-mcp

Built for how agents work on real Tibero schemas실제 Tibero 스키마를 다루는 에이전트에 맞췄습니다

Earlier Tibero MCP servers handed the model a raw SQL pipe with commits on and left you to find a JDBC jar. This one starts from safety and works up. 기존 Tibero MCP 서버는 커밋까지 되는 SQL 통로를 모델에 그대로 열어 주고, JDBC jar는 사용자가 알아서 구해야 했습니다. 이 서버는 안전에서 출발합니다.

Safe by default기본값이 안전합니다

Tibero ignores the JDBC read-only flag and has no SET TRANSACTION READ ONLY, so the server enforces read-only itself, in layers: Tibero는 JDBC 읽기 전용 플래그를 무시하고 SET TRANSACTION READ ONLY도 없습니다. 그래서 서버가 여러 겹으로 직접 막습니다.

Schema discovery that reads comments주석을 읽는 스키마 탐색

Search tables and columns by their comments, then get columns, keys, foreign keys and indexes in one call. 주석으로 테이블과 컬럼을 검색하고, 컬럼·키·외래키·인덱스를 한 번의 호출로 확인합니다.

Results an agent can use에이전트가 바로 쓰는 결과

Typed JSON, a row cap with a truncated flag, timeouts, plans as a tree, and errors that say what to try next. 타입이 살아 있는 JSON, 행 수 상한과 truncated 표시, 타임아웃, 트리 형태의 실행 계획, 다음 행동을 알려 주는 오류 메시지.

No driver hunting드라이버를 찾아다닐 필요 없음

The official JDBC driver comes from Maven Central on first run, checked against a pinned SHA-1. 공식 JDBC 드라이버를 첫 실행 때 Maven Central에서 받아 고정된 SHA-1로 검증합니다.

Runs alongside other agents다른 에이전트와 함께 운영

stdio or Streamable HTTP, automatic reconnect, and a clean exit when the client leaves. stdio와 Streamable HTTP, 자동 재연결, 클라이언트가 떠나면 깔끔한 종료.

  1. Clone내려받기

  3. Register클라이언트에 등록

The driver, without the scavenger hunt드라이버는 알아서 준비됩니다

TmaxTibero publishes its JDBC driver on Maven Central with GPG signatures. tibero-mcp downloads that exact build once, refuses it if the checksum differs, and caches it. Nothing proprietary is stored in the repository, and you can point TIBERO_JDBC_JAR at a jar you already have. TmaxTibero는 JDBC 드라이버를 GPG 서명과 함께 Maven Central에 배포합니다. tibero-mcp는 정확히 그 빌드를 한 번 내려받고, 체크섬이 다르면 사용하지 않으며, 캐시해 둡니다. 저장소에는 독점 바이너리가 없고, 이미 가진 jar가 있다면 TIBERO_JDBC_JAR로 지정할 수 있습니다.
